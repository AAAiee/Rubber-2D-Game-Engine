# Editor

## Functionalities
#### Entity Selection
Select any entity in the scene by clicking on it with the left mouse button.  
![EntitySelection](https://github.com/AAAiee/Rubber-2D-Game-Engine/blob/ECS_ENTT_IMPL_EDITOR/Editor%20Demo/EntitySelect.gif)

#### Add/Remove Components
Right-click the **Add Component** button to add components. Click the “..” in the top-right corner of a component panel to remove that component from the entity.  
![Add/RemovingComponent](https://github.com/AAAiee/Rubber-2D-Game-Engine/blob/ECS_ENTT_IMPL_EDITOR/Editor%20Demo/AddOrRemovingComponent.gif)

#### Camera Component Demo
The Camera Component now supports both orthographic and perspective projection types, with an option for fixed or variable aspect ratio.  
![CameraComponentDemo](https://github.com/AAAiee/Rubber-2D-Game-Engine/blob/ECS_ENTT_IMPL_EDITOR/Editor%20Demo/CameraComponentDemo.gif)

#### Entity Creation Demo
Right-click any empty space in the Scene Hierarchy panel to create a new entity. You can then modify its parameters as you wish.  
![Demo](https://github.com/AAAiee/Rubber-2D-Game-Engine/blob/ECS_ENTT_IMPL_EDITOR/Editor%20Demo/CreateEntityAndDemo-ezgif.com-video-to-gif-converter.gif)
